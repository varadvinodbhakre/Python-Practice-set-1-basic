# 🐍 Python Practice Set 1

This repository contains my **Python Practice Set 1**, where I have solved basic Python programming problems to strengthen my fundamentals.

The main purpose of this practice set is to understand the basic syntax and concepts of Python through simple programs.

## 📚 Topics Covered

* Print Statement
* Comments
* Variables
* Data Types
* String
* Integer
* Float
* Boolean
* Type Casting
* User Input
* Arithmetic Operators
* Escape Sequences
* Square and Cube of a Number
* Basic Calculator

## 📝 Programs Included

### Q1. First Python Program

A simple program to print:

```text
Hello, World! Welcome To Python...
```

### Q2. Print a Poem

Printing a short poem using a **single `print()` statement** and `\n` for a new line.

### Q3. Variables and Data Types

Created variables for:

* Name → String
* Age → Integer
* Height → Float
* Student status → Boolean

Example:

```python
name = "Varad"
age = 20
height = 165
is_student = True
```

### Q4. Typecasting Practice

Converted a string into an integer using `int()`.

```python
a = "45"
print("Addition =", int(a) + 10)
```

### Q5. Taking User Input

Used `input()` to take the user's favourite food and display it.

```python
food = input("Enter your favourite food : ")
print("Wow I also like", food)
```

### Q6. Simple Calculator

Created a basic calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

```python
a = int(input("Enter first number : "))
b = int(input("Enter second number : "))

print("a + b =", a + b)
print("a - b =", a - b)
print("a * b =", a * b)
print("a / b =", a / b)
```

### Q7. Escape Sequences

Practiced escape sequences such as:

* `\n` → New line
* `\t` → Tab

Example:

```python
print('Hello "Python" World! \nThis is on a new line.')
```

### Q8. Operator Challenge

Takes a number from the user and calculates its:

* Square using `**2`
* Cube using `**3`

```python
num = int(input("Enter any number : "))

print("Square of number :", num ** 2)
print("Cube of number :", num ** 3)
```
